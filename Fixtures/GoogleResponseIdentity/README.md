# Google response identity at emission

`identity.json` is generated by `Scripts/google-response-identity-oracle.mjs`
from the exact candidate source. The Google SDK is replaced by a deterministic
chunk generator; the real upstream adapter and transcript bridge execute.
No provider request or credential is used.

The eight cases cover both Google Generative AI and Google Vertex, each with
an immediate ID, a late ID, no ID, and a later replacement ID. All eight source
observations also match accepted revision `19451accdeec671c1f4da9eafac8fc270f510ef4`.

In both revisions the adapter emits `start` before consuming response chunks.
Its initial response ID is absent. It retains the first nonempty server ID for
the terminal result and keeps the requested model ID throughout. Thus Swift's
old first-chunk ID requirement and nonnil start ID were pre-existing semantic
port defects, not new candidate requirements.

`Scripts/pi-ai-emission-snapshots.mjs` records events synchronously in the
upstream `EventStream.push` method before its mutable partial-message references
enter the queue. It forwards the original event unchanged. Async consumption
then reads the saved snapshot. Cloning only inside a `for await` body is too
late: subsequent upstream mutations may already be visible, and adding an
`await` can change old fixtures without changing event-time provider semantics.

Regression evidence:

- Before the Swift fix, `GoogleResponseIdentityTests` reported a mismatched
  nonnil start ID and rejected the late-ID case as `first Google event is
  missing responseId` (`.build/schema6-probe/google-identity-red.log`).
- After the fix, all eight identity cases and the existing seven Google adapter
  tests pass (`.build/schema6-probe/google-identity-green.log`).
- A direct helper check confirmed that a later mutation stays visible through
  the original source event while its emission snapshot remains unchanged.

Regenerate with:

```sh
node --import ./.build/upstreams/pi/node_modules/tsx/dist/loader.mjs \
  Scripts/google-response-identity-oracle.mjs .build/schema6-upstream \
  > Fixtures/GoogleResponseIdentity/identity.json
```
